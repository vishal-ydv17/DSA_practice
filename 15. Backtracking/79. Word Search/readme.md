## Quick Overview

* **Problem Type**: Backtracking, Recursion, Matrix

* **Difficulty**: Medium

* **Key Concept**: Backtracking & DFS

* **Solution**: Use DFS and backtracking to search for the word starting from every cell in the board. At each step, check whether the current cell matches the required character, mark it as visited, and recursively explore the four adjacent cells. After exploring, restore the cell so it can be used in other paths.
