## Quick Overview

* **Problem Type**: Backtracking, Recursion, Matrix

* **Difficulty**: Hard

* **Key Concept**: Backtracking & Constraint Checking

* **Solution**: Use backtracking to place one queen in each row. For every row, try placing the queen in each column and check whether the position is safe from other queens by checking the same column and both diagonals. If a valid position is found, place the queen and recursively solve the next row. If no position works, backtrack and try another column.
