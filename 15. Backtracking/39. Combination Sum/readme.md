## Quick Overview

* **Problem Type**: Backtracking, Recursion, Array

* **Difficulty**: Medium

* **Key Concept**: Backtracking & Recursion

* **Solution**: Use backtracking to generate all combinations whose sum equals the target. At each step, choose a candidate and recursively continue with the remaining target. Since the same number can be used multiple times, we continue from the current index. When the target becomes `0`, add the current combination to the result.
