## Quick Overview

* **Problem Type**: Array, Backtracking
* **Difficulty**: Medium
* **Key Concept**: Backtracking & Recursion
* **Solution**: Generate all possible subsets by making a choice for each element: **include it or exclude it**. Use recursion/backtracking to explore both choices and add every generated combination to the result. This produces all `2ⁿ` possible subsets of the array.
