## Quick Overview

* **Problem Type**: Backtracking, Recursion, String

* **Difficulty**: Medium

* **Key Concept**: Backtracking & Recursion

* **Solution**: Use backtracking to partition the string into all possible substrings. At each step, choose a substring only if it is a palindrome, add it to the current partition, and recursively process the remaining string. When the entire string is processed, add the partition to the result.
