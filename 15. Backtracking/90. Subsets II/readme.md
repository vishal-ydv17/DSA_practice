## Quick Overview

* **Problem Type**: Backtracking, Recursion, Array

* **Difficulty**: Medium

* **Key Concept**: Backtracking & Duplicate Handling

* **Solution**: First, sort the array so duplicate elements are placed next to each other. Then use backtracking to generate all possible subsets. At each level, skip duplicate elements using `if (i > start && nums[i] === nums[i - 1])` so that the same subset is not generated multiple times.
