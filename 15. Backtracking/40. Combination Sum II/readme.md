## Quick Overview

* **Problem Type**: Backtracking, Recursion, Array

* **Difficulty**: Medium

* **Key Concept**: Backtracking, Sorting & Duplicate Handling

* **Solution**: First, sort the array so duplicate elements are next to each other. Then use backtracking to find combinations whose sum equals the target. Each number can be used only once, so the next recursive call starts from `i + 1`. Skip duplicate values at the same recursion level to avoid generating duplicate combinations.
