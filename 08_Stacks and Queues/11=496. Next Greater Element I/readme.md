* **Difficulty:** Easy
* **Key Concept:** Monotonic Stack & Next Greater Element
* **Solution:** Traverse `nums2` using a monotonic decreasing stack. When the current element is greater than the stack's top, it becomes the next greater element for that value. Store the result in a hash map and use it to build the answer for `nums1`.
