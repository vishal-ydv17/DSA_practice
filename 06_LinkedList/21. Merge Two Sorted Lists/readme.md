## Quick Overview

* **Problem Type**: Linked List, Recursion
* **Difficulty**: Easy
* **Key Concept**: Iterative Merge & Recursive Merge
* **Solution**: This solution includes **two approaches**. The first iteratively compares the current nodes of both linked lists, appending the smaller node to the merged list until one list is exhausted, then attaches the remaining nodes. The second approach uses **recursion**, repeatedly choosing the smaller current node and recursively merging the rest of the lists until the base case is reached.
