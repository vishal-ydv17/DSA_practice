## Quick Overview

* **Problem Type**: Linked List, Two Pointers, Hash Table
* **Difficulty**: Easy
* **Key Concept**: Pointer Switching & Hash Set
* **Solution**: This solution includes **two approaches**. The first uses a **Hash Set** to store all nodes of one linked list and then checks for the first common node while traversing the second list. The optimized approach uses **two pointers** that switch to the other list after reaching the end. This equalizes the distance traveled by both pointers, allowing them to meet at the intersection node or reach `null` together if no intersection exists.
