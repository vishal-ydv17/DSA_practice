## Quick Overview

* **Problem Type**: Linked List, Recursion
* **Difficulty**: Medium
* **Key Concept**: Pair Swapping & Pointer Manipulation
* **Solution**: This solution includes **two approaches**. The first uses **recursion** to swap each pair of adjacent nodes. The second uses an **iterative approach** with pointer manipulation to swap two nodes at a time while traversing the linked list. If the list has an odd number of nodes, the last node remains unchanged.
