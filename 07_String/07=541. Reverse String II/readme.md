* **Problem Type:** String, Two Pointers
* **Difficulty:** Easy
* **Key Concept:** String Manipulation & Two Pointers
* **Solution:** Traverse the string in groups of `2k` characters. Reverse the first `k` characters of each group. If fewer than `k` characters remain, reverse all of them; if between `k` and `2k` remain, reverse only the first `k`.
