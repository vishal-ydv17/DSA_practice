* **Problem Type:** Greedy, String, Counting
* **Difficulty:** Easy
* **Key Concept:** Greedy & Balance Tracking
* **Solution:** Traverse the string and maintain a balance count. Increase the count for `L` and decrease it for `R`. Whenever the balance becomes `0`, one balanced substring is found, so increase the answer.
