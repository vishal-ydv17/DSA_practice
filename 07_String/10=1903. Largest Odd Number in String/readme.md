* **Problem Type:** String, Greedy
* **Difficulty:** Easy
* **Key Concept:** Greedy & Finding the Rightmost Odd Digit
* **Solution:** Traverse the string from the end and find the first odd digit. Since the number must be as large as possible, keep the entire prefix ending at that odd digit. If no odd digit exists, return an empty string.
