===========================================================
TOPOLOGICAL SORT USING BFS (KAHN'S ALGORITHM)
===========================================================

LOGIC
-----
Topological sort is only possible on a DAG (no cycles). We use
"indegree" (number of incoming edges) to decide order:
  - A node with indegree 0 has no unresolved prerequisites, so it's
    safe to place in the result right away.
  - When we place a node, we "remove" it by decrementing the
    indegree of its neighbors (one prerequisite resolved for them).
  - Any neighbor whose indegree drops to 0 becomes safe too, so we
    queue it up next.

This is BFS, but using indegree instead of a visited flag.

CYCLE CHECK (bonus): if the graph has a cycle, the nodes in that
cycle depend on each other and never reach indegree 0, so they never
get added to `ans`. That means `ans.length !== n` -> cycle exists.


EXAMPLE (from the given graph)
--------------------------------
indegree = [2, 2, 1, 1, 0, 0]   (nodes 4 and 5 start ready)

q = [4, 5]
pop 4 -> ans=[4]  -> lowers indegree of 0,1 -> [1,1,1,1,0,0]
pop 5 -> ans=[4,5] -> lowers indegree of 0,2 -> [0,1,0,1,0,0] -> push 0,2
pop 0 -> ans=[4,5,0] -> no neighbors
pop 2 -> ans=[4,5,0,2] -> lowers indegree of 3 -> [0,1,0,0,0,0] -> push 3
pop 3 -> ans=[4,5,0,2,3] -> lowers indegree of 1 -> push 1
pop 1 -> ans=[4,5,0,2,3,1] -> no neighbors

Final: ans = [4, 5, 0, 2, 3, 1], length 6 = n -> "Graph has no cycle"


COMPLEXITY
----------
Time:  O(V + E)  — building indegree + BFS both touch each node/edge once
Space: O(V)      — indegree array, queue, and ans array
