## Quick Overview

* **Problem Type**: Binary Tree, Recursion, Depth-First Search
* **Difficulty**: Medium
* **Key Concept**: Recursive Tree Traversal
* **Solution**: Use recursion to search for nodes `p` and `q` in the left and right subtrees. If one node is found in each subtree, the current node is their Lowest Common Ancestor. If the current node is either `p` or `q`, return it directly and propagate the result back through the recursion.
