## Quick Overview

* **Problem Type**: Binary Search Tree, Inorder Traversal
* **Difficulty**: Medium
* **Key Concept**: Inorder Traversal
* **Solution**: Use the property of a Binary Search Tree that **inorder traversal visits nodes in sorted order**. Traverse the tree using inorder traversal and decrease `k` whenever a node is visited. When `k` becomes `0`, the current node contains the kth smallest value.
