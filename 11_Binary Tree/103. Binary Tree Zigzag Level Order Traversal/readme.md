## Quick Overview

* **Problem Type**: Binary Tree, BFS, Queue
* **Difficulty**: Medium
* **Key Concept**: Level Order Traversal & Direction Reversal
* **Solution**: Perform a normal level-order traversal using a queue. Process each level separately and alternate the traversal direction after every level. For one level, store nodes from left to right, and for the next level, reverse the order to create the required zigzag pattern.
