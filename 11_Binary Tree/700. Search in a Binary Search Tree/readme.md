## Quick Overview

* **Problem Type**: Binary Tree, Binary Search Tree
* **Difficulty**: Easy
* **Key Concept**: BST Property
* **Solution**: Use the properties of a Binary Search Tree to efficiently search for the target value. If the current node's value equals the target, return the node. If the target is smaller, move to the left subtree; if it is larger, move to the right subtree. This avoids searching unnecessary parts of the tree.
