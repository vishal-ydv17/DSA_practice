## Quick Overview

* **Problem Type**: Binary Tree, Depth-First Search
* **Difficulty**: Easy
* **Key Concept**: Recursion, Height of Tree & Postorder Traversal
* **Solution**: Calculate the height of each subtree using recursion. At every node, the possible diameter passing through that node is the sum of the heights of its left and right subtrees. Keep track of the maximum diameter found while calculating the height of each node.
