## Quick Overview

* **Problem Type**: Binary Tree, Depth-First Search
* **Difficulty**: Easy
* **Key Concept**: Recursion, Top-Down & Bottom-Up
* **Solution**: This solution includes **two approaches**. The **top-down approach** keeps track of the current path sum while traversing from the root toward the leaf. The **bottom-up approach** reduces the target sum as we move down the tree and checks whether the remaining sum matches the value of a leaf node.
