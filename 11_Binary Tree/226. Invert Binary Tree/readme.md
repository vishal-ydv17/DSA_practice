## Quick Overview

* **Problem Type**: Binary Tree, Recursion
* **Difficulty**: Easy
* **Key Concept**: Tree Traversal & Swapping Children
* **Solution**: Traverse the binary tree recursively and swap the left and right child of every node. Continue the same process for both subtrees until all nodes have been inverted, then return the root of the inverted tree.
