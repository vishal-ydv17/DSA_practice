## Quick Overview

* **Problem Type**: Binary Tree, Depth-First Search
* **Difficulty**: Easy
* **Key Concept**: Recursion & Height Difference
* **Solution**: Calculate the height of the left and right subtrees recursively for every node. If the difference between their heights is greater than `1`, the tree is not balanced. Return the height of each subtree while checking the balance condition at every node.
