## Quick Overview

* **Problem Type**: Binary Tree, Recursion, Queue
* **Difficulty**: Easy
* **Key Concept**: Mirror Comparison, Recursion & Iteration
* **Solution**: This solution includes **two approaches**. The first uses **recursion** to compare the left subtree of one side with the right subtree of the other side, checking whether they are mirror images. The second uses an **iterative approach with a queue** to compare corresponding nodes from both sides level by level.
