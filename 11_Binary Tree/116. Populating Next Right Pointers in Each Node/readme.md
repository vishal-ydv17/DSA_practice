## Quick Overview

* **Problem Type**: Binary Tree, BFS, Linked List
* **Difficulty**: Medium
* **Key Concept**: Level Order Traversal & Next Pointers
* **Solution**: This solution includes **two approaches**. The first uses **BFS with a queue** to process each level and connect every node to the next node in the same level. The second takes advantage of the tree being **perfect** and connects nodes directly using already established `next` pointers, achieving an efficient constant extra-space approach.
