## Quick Overview

* **Problem Type**: Binary Tree, Depth-First Search, Recursion
* **Difficulty**: Hard
* **Key Concept**: DFS & Maximum Path Sum
* **Solution**: Use a recursive DFS to calculate the maximum path sum that can be extended from each node to its parent. At every node, ignore negative contributions from the left or right subtree, calculate the path passing through the current node, and update the global maximum. Return the best single-branch path to the parent.
