## Quick Overview

* **Problem Type**: Dynamic Programming, Array

* **Difficulty**: Medium

* **Key Concept**: Dynamic Programming

* **Solution**: Use a DP array where `dp[i]` represents the length of the longest increasing subsequence ending at index `i`. For every element, check all previous elements. If `nums[j] < nums[i]`, update `dp[i]` using `dp[i] = max(dp[i], dp[j] + 1)`. The maximum value in the DP array gives the length of the longest increasing subsequence.
