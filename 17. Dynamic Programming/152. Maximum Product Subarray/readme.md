## Quick Overview

* **Problem Type**: Array, Dynamic Programming

* **Difficulty**: Medium

* **Key Concept**: Dynamic Programming & Tracking Maximum/Minimum

* **Solution**: Keep track of both the maximum and minimum product ending at the current position. A negative number can turn the minimum product into the maximum, so both values are important. For every element, update the maximum and minimum products and keep track of the largest product found so far.
