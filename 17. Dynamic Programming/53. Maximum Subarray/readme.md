## Quick Overview

* **Problem Type**: Array, Dynamic Programming

* **Difficulty**: Medium

* **Key Concept**: Kadane's Algorithm

* **Solution**: Use Kadane's Algorithm to find the maximum sum of a contiguous subarray. Keep a running sum and decide whether to extend the current subarray or start a new one from the current element. At each step, update the maximum sum found so far.
