## Quick Overview

* **Problem Type**: Dynamic Programming, Recursion, Math

* **Difficulty**: Easy

* **Key Concept**: Dynamic Programming & Fibonacci Pattern

* **Solution**: The number of ways to reach step `n` depends on the number of ways to reach the previous two steps. Therefore, use the recurrence `ways(n) = ways(n - 1) + ways(n - 2)`. We can solve it efficiently using two variables to store the previous two results instead of using an extra array.
