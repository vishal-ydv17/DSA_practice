## Quick Overview

* **Problem Type**: Recursion, Dynamic Programming, Math

* **Difficulty**: Easy

* **Key Concept**: Recursion & Dynamic Programming

* **Solution**: Calculate the Fibonacci number using the recurrence relation `F(n) = F(n - 1) + F(n - 2)`. The base cases are `F(0) = 0` and `F(1) = 1`. The solution can be implemented using recursion or an iterative approach with two variables to keep track of the previous two Fibonacci numbers.
