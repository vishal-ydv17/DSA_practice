## Quick Overview

* **Problem Type**: Dynamic Programming, Array

* **Difficulty**: Easy

* **Key Concept**: Dynamic Programming & Bottom-Up Approach

* **Solution**: At each step, calculate the minimum cost needed to reach that step from either of the previous two steps. Use the recurrence `dp[i] = cost[i] + min(dp[i - 1], dp[i - 2])`. The final answer is the minimum cost to reach the top from the last two steps. The space can be optimized by keeping only the previous two costs.
