* **Difficulty:** Medium
* **Key Concept:** Dynamic Programming & Grid Traversal
* **Solution:** Use DP to calculate the number of unique ways to reach each cell. The number of ways to reach a cell is the sum of the ways to reach the cell above and the cell to its left.
