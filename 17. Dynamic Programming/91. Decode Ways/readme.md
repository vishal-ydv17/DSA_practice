## Quick Overview

* **Problem Type**: Dynamic Programming, String

* **Difficulty**: Medium

* **Key Concept**: Dynamic Programming & Recursion

* **Solution**: Use dynamic programming to count the number of ways to decode the string. At each position, check whether the current digit can form a valid single-digit decoding and whether the current two digits form a valid number between `10` and `26`. Add the valid possibilities from the previous states to get the total number of decodings.
