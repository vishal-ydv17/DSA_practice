## Quick Overview

* **Problem Type**: Dynamic Programming, Array

* **Difficulty**: Medium

* **Key Concept**: Dynamic Programming & Circular Array

* **Solution**: Since the houses are arranged in a circle, the first and last houses cannot both be robbed. So, solve the problem in two cases: exclude the last house and rob from the first house to the second-last house, or exclude the first house and rob from the second house to the last house. Take the maximum result from these two cases using the same DP logic as **House Robber I**.
