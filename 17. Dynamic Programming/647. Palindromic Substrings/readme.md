## Quick Overview

* **Problem Type**: Dynamic Programming, String

* **Difficulty**: Medium

* **Key Concept**: Expand Around Center

* **Solution**: Treat every character as the center of an odd-length palindrome and every gap between two characters as the center of an even-length palindrome. Expand outward while the characters match and count every valid palindrome found.
