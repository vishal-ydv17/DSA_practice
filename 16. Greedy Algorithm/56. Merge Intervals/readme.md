## Quick Overview

* **Problem Type**: Array, Intervals, Sorting

* **Difficulty**: Medium

* **Key Concept**: Sorting & Interval Merging

* **Solution**: First, sort the intervals by their starting time. Then traverse the intervals and compare each interval with the last interval in the result. If they overlap, merge them by updating the ending time. Otherwise, add the current interval to the result as a separate interval.
