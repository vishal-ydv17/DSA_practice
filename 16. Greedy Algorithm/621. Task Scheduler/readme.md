## Quick Overview

* **Problem Type**: Greedy, Hash Table, Counting, Sorting

* **Difficulty**: Medium

* **Key Concept**: Greedy & Frequency Counting

* **Solution**: Count the frequency of each task and identify the task with the highest frequency. Use the most frequent task to create the scheduling pattern and calculate the idle slots required between repeated tasks. Fill these idle slots with the remaining tasks whenever possible. The final answer is the larger of the calculated schedule length and the total number of tasks.
