## Quick Overview

* **Problem Type**: Greedy, Array

* **Difficulty**: Easy

* **Key Concept**: Greedy & Simulation

* **Solution**: Keep track of the number of `$5` and `$10` bills available. For a `$5` bill, simply store it. For a `$10` bill, give one `$5` as change. For a `$20` bill, prefer giving one `$10` and one `$5`; if that is not possible, give three `$5` bills. If the required change cannot be given, return `false`.
