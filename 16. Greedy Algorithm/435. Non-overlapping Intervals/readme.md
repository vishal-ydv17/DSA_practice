## Quick Overview

* **Problem Type**: Greedy, Sorting, Intervals

* **Difficulty**: Medium

* **Key Concept**: Greedy & Interval Scheduling

* **Solution**: Sort the intervals by their ending time. Keep track of the end of the last non-overlapping interval. If the current interval starts before that end, it overlaps, so remove it. Otherwise, keep the current interval and update the end. This greedy approach keeps intervals that finish earliest and minimizes the number of removals.
