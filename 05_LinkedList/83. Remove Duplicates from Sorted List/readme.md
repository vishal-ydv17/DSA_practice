## Quick Overview

* **Problem Type**: Linked List
* **Difficulty**: Easy
* **Key Concept**: Pointer Manipulation
* **Solution**: Traverse the sorted linked list using a single pointer. Whenever two consecutive nodes have the same value, skip the duplicate by updating the `next` pointer. Since the list is already sorted, all duplicates appear next to each other, making them easy to remove in one traversal.
