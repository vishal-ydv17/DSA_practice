## Quick Overview
- **Problem Type**: Array, Matrix  
- **Difficulty**: Easy  
- **Key Concept**: Diagonal traversal  
- **Solution Summary**:  
  Sum the **primary diagonal** (from top-left to bottom-right) and the **secondary diagonal** (from top-right to bottom-left).  
  If the matrix has an odd size, subtract the center element once to avoid double-counting.
