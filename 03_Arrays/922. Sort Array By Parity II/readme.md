## Quick Overview
- **Problem Type**: Array, Two Pointers  
- **Difficulty**: Easy  
- **Key Concept**: Even–Odd Positioning  
- **Solution Summary**:  
  Rearrange the array so that:
  - every **even index** contains an even number,  
  - every **odd index** contains an odd number.  
  Use two pointers to find mismatched parity and swap until all elements are correctly placed.
