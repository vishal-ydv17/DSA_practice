## Quick Overview
- **Problem Type**: Array, Hash Set  
- **Difficulty**: Easy  
- **Key Concept**: Difference of sums  
- **Solution Summary**:  
  Calculate total candies of Alice and Bob.  
  To make totals equal after swap, we need:  
  `a - b = (sumA - sumB) / 2`.  
  Store Bob’s candies in a set and check for a matching value for each of Alice’s candies.
