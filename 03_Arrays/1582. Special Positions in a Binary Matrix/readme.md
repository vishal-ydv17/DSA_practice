## Quick Overview
- **Problem Type**: Matrix, Counting  
- **Difficulty**: Easy  
- **Key Concept**: Unique 1 in row & column  
- **Solution Summary**:  
  A *special position* is a cell with value `1` such that it’s the **only `1` in its row** and **only `1` in its column**.  
  Count and return all such positions.
