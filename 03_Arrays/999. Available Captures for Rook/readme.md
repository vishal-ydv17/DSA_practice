## Quick Overview
- **Problem Type**: Array, Simulation  
- **Difficulty**: Easy  
- **Key Concept**: Board traversal from rook position  
- **Solution Summary**:  
  Find the **rook ('R')** in the chessboard.  
  From the rook’s position, check in all **four directions** (up, down, left, right) until:
  - you hit a **bishop ('B')** — stop in that direction, no capture  
  - you hit a **pawn ('p')** — count it as a capture and stop in that direction  
  Add up all valid pawn captures.
