## Quick Overview

* **Problem Type**: Array, Bit Manipulation
* **Difficulty**: Easy
* **Key Concept**: XOR Properties
* **Solution**: Start with the given first element of the original array. Since `encoded[i] = arr[i] XOR arr[i + 1]`, use the XOR property (`A XOR B XOR A = B`) to recover each next element one by one and reconstruct the entire original array.
