## Quick Overview

* **Problem Type**: String, Sliding Window, Hash Set
* **Difficulty**: Medium
* **Key Concept**: Sliding Window & Two Pointers
* **Solution**: Use a **sliding window** to maintain a substring containing only unique characters. Expand the window by moving the right pointer, and whenever a duplicate character is found, move the left pointer forward until the duplicate is removed. Keep updating the maximum window length to get the longest substring without repeating characters.
