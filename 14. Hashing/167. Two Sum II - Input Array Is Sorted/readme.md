## Quick Overview

* **Problem Type**: Array, Two Pointers
* **Difficulty**: Medium
* **Key Concept**: Two Pointer Technique
* **Solution**: This solution includes **two approaches**. The first uses a brute-force approach by checking every possible pair of elements. The optimized approach uses **two pointers**, one starting from the beginning and the other from the end of the sorted array. If the sum is too small, move the left pointer forward; if the sum is too large, move the right pointer backward. When the sum equals the target, return the two indices.
