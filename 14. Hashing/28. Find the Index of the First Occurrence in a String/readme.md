## Quick Overview

* **Problem Type**: String, Two Pointers
* **Difficulty**: Easy
* **Key Concept**: String Matching & Sliding Window
* **Solution**: This solution includes **three approaches**. The approaches check whether `needle` occurs inside `haystack` by comparing characters at each possible starting position. The optimized sliding-window approach checks a window of size `needle.length` and compares it with `needle` to find the first matching position.
