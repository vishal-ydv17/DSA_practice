## Quick Overview

* **Problem Type**: Array, Sliding Window, Deque
* **Difficulty**: Hard
* **Key Concept**: Sliding Window & Monotonic Deque
* **Solution**: This solution includes **two approaches**. The first uses a brute-force approach by finding the maximum element in every window of size `k`. The optimized approach uses a **monotonic decreasing deque** to keep track of useful elements for each window. Remove elements that are outside the current window and remove smaller elements from the back, so the front always contains the maximum value of the current window.
