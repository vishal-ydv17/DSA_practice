## Quick Overview

* **Problem Type**: String, Hash Table, Sorting
* **Difficulty**: Easy
* **Key Concept**: Character Frequency Counting
* **Solution**: This solution includes **two approaches**. The first sorts both strings and compares the sorted results. The second uses a **frequency map** to count each character in both strings and compares their frequencies. If every character has the same frequency in both strings, they are anagrams.
