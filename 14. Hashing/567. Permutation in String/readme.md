## Quick Overview

* **Problem Type**: String, Sliding Window, Hash Table
* **Difficulty**: Medium
* **Key Concept**: Frequency Counting & Sliding Window
* **Solution**: This solution includes **two approaches**. The first checks each possible substring of `s2` having the same length as `s1` and compares their character frequencies. The optimized approach uses a **sliding window** to maintain character frequencies while moving through `s2`. If the frequency of the current window matches the frequency of `s1`, then a permutation of `s1` exists in `s2`.
